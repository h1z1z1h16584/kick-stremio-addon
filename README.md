# Kick Stremio Add-on

Watch 100+ Kick live streams and recorded VODs directly inside Stremio (compatible with Desktop, Web, Android TV, and PS5 browser).

### Installation
1. Click here to [Install to Stremio](stremio://zarranomma2996.alwaysdata.net/manifest.json)
2. Or copy this manifest link and paste it into Stremio's Add-on search bar:
   `[https://zarranomma2996.alwaysdata.net/manifest.json](https://zarranomma2996.alwaysdata.net/manifest.json)`

### Features
- 🔴 Live / ❌ Offline indicators
- Top 100+ English livestreams
- Search channels by username
- Past recorded broadcasts (VODs)
- Native CORS proxy for PS5 and browser playback
